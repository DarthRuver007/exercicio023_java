# Programa para solicitar número inicial e número final ao usuário, calcular e mostrar a média aritmética dos números inteiros incluindo na soma o número inciial e final usando while.

Programa que solicita número inicial e número final ao usuário, calcula e mostra a média aritmética dos números inteiros incluindo na soma o número inciial e final usando while.

Desenvolvido utilizado JDK 1.8 e NetBeans 13.
